# 公众号质量 — 相对复盘

先读并遵守 [`../_shared/contracts.md`](../_shared/contracts.md)。不要复制或改写降级表；只引用它。不要调用扩展、不要 fetch URL、不要声称推荐算法因果。

## 输入

接受任一种：作者粘贴的正文；或仓库文件（优先 `examples/articles.interchange.json`，CSV 孪生亦可）。

- 以 `{` 或 `[` 开头 → JSON。对象带 `articles` 数组则数该数组；否则若本身是文章对象数组也行。
- 否则按 CSV：首行表头，必须能映射到 `title` 与 `read_count`（缺列则在报告里标明数据缺口，不编造）。
- 无扩展名时按上面两条嗅探，不要只认 `.json` / `.csv`。

一篇 = 一条文章对象 / 一行。篇数 = 本轮作者本号语料条数，不是阅读量。

## 档位（打开 contracts.md 的表，不要另造表）

**几乎无稿**（空粘贴，或只有 1 篇）：检查清单模式。文首声明 **不做个人史排序**。列出还缺的字段与下一篇可试的结构动作。不编造个人史证据。若本档发出 `## 04 实验`，同样必须含：**可粘贴标题**、**开头写法（约 150 字）**、**只改一个变量**、**发后回灌**。

**&lt;10**（含金样 3 篇）：

- 文首声明 **不做个人史排序**。禁止分位表、名次表。
- 结论做结构规律摘要，不比较「谁更爆」。
- 因子 ≥1 条须带可定位依据（表行 #、标题或引用句）。给不出依据的句子标 **`【推测】`**。
- **不要**用 `【低置信】`（留给高篇数 + 低阅读）。
- `## 03 候选` 至少 3 条；各附一句相对本语料的理由；禁止「必爆」。
- `## 04 实验` 必须含：**可粘贴标题**、**开头写法（约 150 字）**、**只改一个变量**、**发后回灌**（再导出或粘贴，对照本实验）。

**10–29**（夹具 `examples/articles.band-10-29.json`）：粗分「稍好 / 普通 / 较差」并点名所依据的篇目标识。结构对照 + 1–2 个实验。**不做细分位**。因子 **≥2 条**，且落在**非重复**结构维度（见下「因子规则」）；每条须有依据；整篇报告 **≥1 条实质 `sf-*` 引用**。

**≥30**（夹具 `examples/articles.band-30.json`）：允许相对排序。结论至少含 **≥3 篇**相对排序或分位说明；因子 **≥2 条**，且落在**非重复**结构维度；每条点名比较依据（标题形态 / 发布时间 / 互动比等）；整篇报告 **≥1 条实质 `sf-*` 引用**。阅读整体偏低时文首标 **`【低置信】`**，结论只服务下一篇实验。形状可对照 `examples/sample-report-band-30.md`，须依据本轮数据。

全程 **不声称推荐算法因果**。阅读量个位数不表示无权使用。

## 因子规则（≥10 强制；&lt;10 亦宜遵守）

- **非重复维度：** 两条因子须落在不同结构轴，例如：标题前段形态（sf-03）/ 开场落地（sf-01、sf-02）/ 段落节拍（sf-04）/ 末句（sf-05）/ 发布时间桶。仅换说法重复「物件+异常」→ 算 **一条** 模式，必须换轴再写第二条。
- **实质 `sf-*` 引用（≥10 强制）：** 每条 `sf-0N` 引用必须同时写出：信号是什么 + 对照了哪一行的标题/开场。禁止裸挂名「(sf-01)」。相关主张若证据不足可标 **`【推测】`**，但 `sf-*` 本身仍须带信号与行级对照，不得退回为仅点名。
- **禁止作因子：** 「推荐占比」「推流」「算法」等渠道描述不得写成结构因子；可一句带过为渠道观察，但**禁止**算法因果叙事——优先省略。

## 可选对标粘贴

作者可另贴一段**已经出现在对话里的公开正文**（标题+开头即可）。**不要 fetch URL，不要去扒他号阅读量。**

拆解只覆盖这三维，写进 `## 02 因子`（或结论里的结构摘要），**不另开第五块**：

1. **开头钩子** — 第一句如何落地  
2. **标题结构** — 前段是否给出场所/对象  
3. **段落节奏** — 一句一拍还是解释过多  

每条对照可引用 `references/` 的 sf-01…sf-05。文中写一句：**价值判断由作者定**（值不值得学不是模型的结论）。

无对标粘贴：仍用 `references/` 摘要跑结构对照，不要停下来索要正文。

## 输出骨架

只输出这四块，标题字面如下：

```markdown
## 01 结论
## 02 因子
## 03 候选
## 04 实验
```

`## 04 实验` 最小形状（任何发出 04 的档位均须齐全）：

```markdown
## 04 实验
- **可粘贴标题：** 《……》
- **开头写法（约 150 字）：** ……
- **只改一个变量：** ……
- **发后回灌：** ……
```

形状可对照 `examples/sample-report.md`，但必须依据**作者这一轮**的数据，不要照抄样例句子。
