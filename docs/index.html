公众号质量 Copilot

本号相对复盘 · 结构教练 · 可粘贴下一篇实验。
不保证推荐，不破解推流，不扒他号。

两分钟跑通 查看仓库

写公众号、手里有自己的历史稿，想看结构规律、下一篇怎么试——而不是听「必爆」话术。

你得到什么

  1. 01

    相对复盘

    按篇数诚实降级：少稿当结构教练，多稿才谈相对排序。不做个人史算命。

  2. 02

    固定四块报告

    结论 → 因子 → 标题候选 → 实验。契约钉死骨架，模型少自由发挥跑题。

  3. 03

    可粘贴实验

    「04 实验」含标题、开头写法、单变量、发后回灌——写完能直接开写。

  4. 04

    本号导出

    Chrome MV3 扩展：已登录后台列表页导出到本机 JSON；失败则粘贴同形状数据。

两分钟跑通

不依赖扩展。先克隆或打开仓库，在仓库根目录执行：

npx skills add . --skill gzh-review -a cursor -y
  1. 确认 Skills 里 gzh-review 旁有 _shared
  2. 新开 Agent，加载 Skill，打开金样 JSON，说「复盘」
  3. 对照四块形状与仓库 README

完整安装（Claude Code / Codex 等）与扩展步骤见 仓库 README。

如果你在搜这些

下面是常见说法——本站与仓库正是为这些需求准备的（相对复盘，不是涨粉玄学）：

  • 微信公众号怎么复盘自己的文章 / 本号数据怎么分析
  • 公众号阅读量对比、标题怎么改、下一篇写什么、开头怎么写
  • 公众号后台已发表列表导出 JSON / CSV，贴进 AI（Cursor / Claude）做结构教练
  • Agent Skill、gzh-review、开源、不承诺爆款的内容复盘工具

明确不做

  • 破解推流 / 预测推荐算法
  • 保证推荐、保证爆款
  • 未授权批量采集他号
