# 复盘报告（样例 · Agent Markdown 契约）

> 档位：&lt;10 篇（金样 3 篇）· 不做个人史排序 → 结构教练 + 1 个结构实验  
> 角标字面量见 `skills/_shared/contracts.md`（本档不用【低置信】；该标留给高篇数 + 低阅读）。

---

## 01 结论

**不做个人史排序。** 这 3 篇只够看结构，不够画分位。  
相对可观察的共同点：开场都落在一个具体场景（便利店 / 末班车 / 窗台），而不是抽象抒情。这不证明「会被推荐」。

## 02 因子

1. **具体场景开场（sf-01）** — 信号：第一句先落地地点。依据：`《雨夜便利店的最后一班》` 首句「便利店灯管嗡嗡响」（表行 #1）；`《地铁末班车上的陌生人》` 首句「车厢只剩三个人」（表行 #2）。  
2. **标题前段信息密（sf-03）** — 信号：前 8 字给出场所或对象。依据：三题均在前 8 字给出地点或对象（雨夜便利店 / 地铁末班车 / 窗台上的鸽子）。  
3. **【推测】** — 「便签」会比「鸽子」更像悬念钩子：没有读者访谈或对标原文，不作结构定论。

## 03 候选

1. **《冷柜灯还亮着》** — 相对金样：保留便利店场景，把钩子从「过期便当」收到前 15 字。  
2. **《便签只写了一行》** — 相对金样：末班车篇的物件提前到标题，正文少解释。  
3. **《它们只拍翅膀》** — 相对金样：窗台篇把「沉默」从结尾挪到开头。  

禁止「必爆」。篇数不足，候选只服务下一篇结构实验。

## 04 实验

- **可粘贴标题：** 《冷柜灯还亮着》  
- **开头写法（约 150 字）：** 第一句直接落进便利店冷柜前：写灯管嗡声或玻璃上的雾，点出一件可指认物件（还亮着的冷柜灯、贴着「临期」的便当）。第二句只写人物发现异常时的一个小动作——伸手、停住、看了一眼标签——不交代为什么来店、不抒情。第三句把异常钉死（灯还亮、日期不对），仍不解释原因。前约一百五十字只推进「发现异常」这一个节拍；句式对照表行 #1/#2：地点先落地，再物件加动作。  
- **只改一个变量：** 下一篇仍用具体场景开场，只重写开头钩子密度（标题与后半不动）。  
- **发后回灌：** 再导出或粘贴 → 对照本实验。
