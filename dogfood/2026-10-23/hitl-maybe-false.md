## A · 分页省略号低估总页数

**怀疑：** `totalPagesFromPagerText` 只读 DOM 里能看到的页码数字；WeUI 有 `…` 时末页数字可能不在 DOM → `nextUrl` 过早变 `null` → 少翻页。

**前置：** 列表总页数 **≥ 约 10**（分页条会出现省略号）。页数很少（≤7）可 **S**。

**步骤：**
1. 打开 `mp.weixin.qq.com` 图文/发表列表第 1 页。
2. 看底部分页：是否有 `…`，末页数字是否**可见**（例如能直接看到「16」）。
3. DevTools → Console，粘贴（只读，不改页）：

```js
[...document.querySelectorAll(".weui-desktop-pagination__num, a, span")]
  .map((el) => (el.textContent || "").trim())
  .filter((t) => /^\d+$/.test(t));
```

4. 记下：肉眼总页数 = ____；脚本最大数字 = ____。
5. 勾选扩展「翻完所有页」→ 导出。等下载完。
6. 打开 JSON：`articles.length` ≈ ____；是否明显少于「总页 × 每页条数」（允许近重复折叠后略少）。

**判定：**
- 肉眼末页 ∈ 脚本数字集合，且导出页数合理 → **F**
- 肉眼末页 **不在** DOM 数字里，且导出在中间页就停 / 篇数明显少 → **T**（附分页条截图）
- 账号页数太少看不到 `…` → **S**

**结果：** **F** · 证据：第 1 页分页 DOM = `['1','2','3','4','16']`（有省略号但末页 16 仍在）；勾选翻完所有页后 JSON 拉到 2021 年旧稿（远超单页），未在第 4 页停。HITL 2026-10-23。

## B · 超大 `data:` 下载被拒

**怀疑：** 多页合并后 JSON 很大，`data:application/json,…` URL 触浏览器长度上限 → `chrome.downloads.download` 失败；SW 里 catch 吞掉 → **静默无文件**。

**前置：** 能勾「翻完所有页」；篇数越多越好。理想接近 `MULTI_PAGE_CAP`（50 页）或至少 **十几页以上**。页很少可仍测，但否定力弱。

**步骤：**
1. 勾选「翻完所有页」→ 导出，**不要关**列表页。
2. 等进度结束：Downloads 是否出现 `articles.interchange.json`（或当前固定文件名）？
3. `chrome://extensions` → 本扩展 →「服务工作进程」→ 检查是否有 download / quota / ERR 类报错。
4. 若有文件：文件大小 ____ KB；用编辑器打开是否完整 JSON（末尾 `}` / `]`）。

**判定：**
- 有完整文件 → **F**（本账号体量下未踩上限）
- 进度结束但无文件，或 SW 明确 download reject → **T**
- 无法跑多页 → **S**

**结果：** **F** · 证据：同一次 16 页多页导出，Downloads 完整 JSON ≈ 41.5KB；未出现静默无文件 / download reject。HITL 2026-10-23。（本号未近 MULTI_PAGE_CAP=50，极端体量未测。）

## C · 导出中途乱点导航（stray `complete`）

**怀疑：** `waitTabNavigateComplete` 只听 tab `status === complete`，**不校验 URL**；导出翻页等待时你点到别的 URL，可能误判「本页已到」→ 抽到错页 / 乱序 / 提前结束。

**前置：** 能跑多页导出；准备好另一标签页或同标签可点的链接（如「素材管理」）。

**步骤：**
1. 勾选「翻完所有页」→ 开始导出。
2. **第一二次**列表刚开始跳转、扩展还在转圈时：在**同一标签**点到非列表页（例如左侧别的菜单），或地址栏改到无关 `mp.weixin.qq.com` 路径。
3. 观察：弹窗/状态是继续、报错、卡住，还是安静结束？
4. 若仍下载了 JSON：抽查几条 `url`/`title` 是否混进非列表页内容，或篇数异常少。
5.（对照）再跑一次**全程不要乱点**，对比篇数。

**判定：**
- 乱点后明显坏结果（错页数据 / 异常短 / 卡死无提示）→ **T**
- 乱点被取消/超时/你被踢出列表后重开导出正常；或不乱点路径稳定，乱点仅「自己操作失误」可接受 → **F**（记录实际现象）
- 来不及在跳转窗口操作 → 重试或 **S**

**结果：** **F** · 证据：导出翻页中途同标签点离列表；行为正确（未产出明显脏 JSON / 误抽）。维护者确认「正确」。HITL 2026-10-23。
